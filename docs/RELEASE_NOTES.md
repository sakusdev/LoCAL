LoCAL v0.3.0 プレビュー。同じLANのAndroid・Windows・Linux・macOS間で、クラウドやアカウントを使わずにファイル、テキスト、音声を直接やり取りできます。

この版ではペアリング済み端末間の1対1音声通話を追加しました。発信・着信承認・ミュート・終了に対応し、マイクはユーザーの操作とOS権限の後にだけ開始します。呼制御はQUIC / TLS 1.3、音声はWebRTCのDTLS-SRTPを使い、公開STUN / TURNやクラウド中継は使用しません。

WindowsのH.264画面共有をAndroidから閲覧できる受信経路も追加しました。Android WebViewのWebCodecsデコーダーを使用し、承認・表示・停止ができます。Androidからの画面送信はまだ未対応です。

- 自動発見 + IPアドレス指定
- Ed25519端末ID、両端末で確認する6桁ペアリング、信頼の保存・解除
- QUIC / TLS 1.3のテキスト・ファイル送受信
- 1対1のLAN内音声通話、着信承認、ミュート、終了
- 受信承認、進行状況、キャンセル、再送で中断再開、BLAKE3検証。複数ファイルは各件を個別に承認
- SQLite履歴、手動クリップボード共有、日本語UI、CLI
- 再起動後も開ける保存済み受信ファイル一覧

**Pixel 7aなどは `android-arm64-v8a-debug.apk`、一般的なWindows PCは `windows-x64-setup.exe` を選んでください。** Android受信ファイルは「端末に保存…」で書き出せます。

画面共有の送信はWindows Graphics CaptureとOpenH264ソフトウェアエンコーダーを使用し、最大1280×720・15fpsで申し込みます。受信はWindowsとAndroidに対応します。画面の音声・リモート操作は対象外です。音声通話とAndroid画面受信は実機2台での品質・遅延確認をまだ行っていません。

4種類のAPKはAndroid Debug開発署名付きで、Actionsが署名証明書を検査します。ビルドごとに開発鍵が変わるため、従来のAPKからの更新には再インストールが必要です。先に受信ファイルを書き出してください。Windows/macOSは商用署名・公証なしです。センサー、QR、画像クリップボード、フォルダー直接送信は未対応です。

`SHA256SUMS.txt` と、ソースコミット・配布物一覧を記載した `manifest.json` を添付します。詳細はリポジトリの `docs/QUICKSTART.md` を参照してください。
