LoCAL v0.4.0 プレビュー。同じLANのAndroid・Windows・Linux・macOS間で、クラウドやアカウントを使わずにデータと端末機能を直接共有できます。

この版ではClipboard Syncを追加しました。同期するペアリング済み端末を選択して明示的に有効化すると、その後コピーした16 KiB以内のテキストを暗号化QUIC接続で同期します。開始前の履歴を勝手にコピーせず、受信内容の再送ループも防止します。手動送信・最新受信テキストの取得にも対応します。

Androidからの画面共有送信にも対応しました。受信側の承認後、Android標準のMediaProjection許可を表示し、MediaCodecでH.264へハードウェアエンコードして既存の画面用QUICストリームへ送ります。共有中はAndroidの常駐通知に表示され、通知から停止できます。縦画面はアスペクト比を保ったまま最大1280×720・15fpsへ収めます。

- 自動発見 + IPアドレス指定
- Ed25519端末ID、両端末で確認する6桁ペアリング、信頼の保存・解除
- QUIC / TLS 1.3のテキスト・ファイル送受信
- 選択端末とのテキストクリップボード同期
- 1対1のLAN内音声通話、着信承認、ミュート、終了
- Windows / Android画面のH.264共有、受信承認、停止
- ファイル受信承認、進行状況、キャンセル、中断再開、BLAKE3検証
- SQLite履歴、日本語UI、CLI

**Pixel 7aなどは `android-arm64-v8a-debug.apk`、一般的なWindows PCは `windows-x64-setup.exe` を選んでください。** Android受信ファイルは「端末に保存…」で書き出せます。

画面共有の音声・リモート操作、画像クリップボード、フォルダー直接送信は対象外です。音声通話とAndroid画面共有は実機2台での品質・遅延確認がまだ必要です。

4種類のAPKはAndroid Debug開発署名付きで、Actionsが署名証明書を検査します。ビルドごとに開発鍵が変わるため、従来のAPKからの更新には再インストールが必要です。Windows/macOSは商用署名・公証なしです。

`SHA256SUMS.txt` と、ソースコミット・配布物一覧を記載した `manifest.json` を添付します。詳細は `docs/QUICKSTART.md` を参照してください。
