LoCAL v0.2.3 プレビュー。同じLANのAndroid・Windows・Linux・macOS間で、クラウドやアカウントを使わずにファイルとテキストを送受信できます。

この版ではAndroidとデスクトップで一度に最大8件のファイルを選んで送れるようにしました。複数のネットワークアダプターがある端末でも、「設定」に表示された接続用アドレスを個別にコピーできます。Android起動時の背景色もアプリ画面に合わせました。

- 自動発見 + IPアドレス指定
- Ed25519端末ID、両端末で確認する6桁ペアリング、信頼の保存・解除
- QUIC / TLS 1.3のテキスト・ファイル送受信
- 受信承認、進行状況、キャンセル、再送で中断再開、BLAKE3検証。複数ファイルは各件を個別に承認
- SQLite履歴、手動クリップボード共有、日本語UI、CLI
- 再起動後も開ける保存済み受信ファイル一覧

**Pixel 7aなどは `android-arm64-v8a-debug.apk`、一般的なWindows PCは `windows-x64-setup.exe` を選んでください。** Android受信ファイルは「端末に保存…」で書き出せます。

v0.2.0からWindows同士の画面共有プレビューを利用できます。ペアリング済みの相手に画面共有を申し込み、受信側で承認すると、WebView2のH.264デコーダーを使って閲覧できます。Windows Graphics CaptureとOpenH264ソフトウェアエンコーダーを使用し、最大1280×720・15fpsで申し込みます。表示の停止と承認拒否ができます。音声・リモート操作は対象外です。Windows実機2台での遅延・描画確認はまだ行っていません。Android・macOS・Linuxは画面共有に未対応です。

4種類のAPKはAndroid Debug開発署名付きで、Actionsが署名証明書を検査します。ビルドごとに開発鍵が変わるため、従来のAPKからの更新には再インストールが必要です。先に受信ファイルを書き出してください。Windows/macOSは商用署名・公証なしです。音声、センサー、QR、画像クリップボード、フォルダー直接送信は未対応です。

`SHA256SUMS.txt` と、ソースコミット・配布物一覧を記載した `manifest.json` を添付します。詳細はリポジトリの `docs/QUICKSTART.md` を参照してください。
